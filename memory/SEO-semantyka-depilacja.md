## 12. Правила, чтобы не получить санкции

1. Не создавать гео-дорвеи под каждый соседний город — только блок `areaServed`.
2. FAQ не дублировать между страницами: каждый вопрос — только на одной странице.
3. Не обещать «100% trwałe usunięcie na zawsze» — писать «redukcja 80–95% + zabiegi podtrzymujące».
4. Не заявлять эффективность лазера на седых/светлых волосах — честно: melanina jest warunkiem.
5. Цены в тексте = ценам в API/Booksy. Расхождение = потеря доверия и rich snippet.
6. Не таргетить услуги, которых нет (depilacja woskiem, sugaring) — только в сравнительных таблицах.
