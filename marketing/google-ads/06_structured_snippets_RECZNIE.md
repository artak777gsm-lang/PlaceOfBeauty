# Структурированное описание — добавляется вручную

Google Ads Editor **не поддерживает импорт структурированных описаний из CSV**:
в документации Editor столбцов для них нет, объект создаётся только через
«Общую библиотеку». Попытка импорта даёт ошибку «Неоднозначный тип строки».

## Веб-интерфейс Google Ads (быстрее всего)

Объекты (Ассеты) → «+» → Структурированное описание → уровень: **Кампания**
`PL | Search | Depilacja laserowa | Grodzisk`

- Язык: польский
- Заголовок: **Usługi** (выбирается из списка Google, свой вписать нельзя)
- Значения (3–10 штук, каждое до 25 знаков):

```
Depilacja laserowa
Pachy
Bikini
Nogi
Wąsik
Pakiet 3 partii
Konsultacja gratis
```

## Google Ads Editor

Общая библиотека → Общие объекты «структурированное описание» → «+» →
те же заголовок и значения → привязать объект к кампании.
