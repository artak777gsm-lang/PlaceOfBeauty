https://ads.google.com/home/tools/ads-editor/). Все тексты проверены на лимиты знаков.

Название кампании во всех файлах одинаковое:
`PL | Search | Depilacja laserowa | Grodzisk`, группа объявлений: `Depilacja laserowa - ogolne`.
Если переименуете кампанию — поправьте колонку `Campaign` во **всех** файлах, иначе Editor
разложит данные по разным кампаниям.

## Порядок импорта

1. Создайте в Editor (или в веб-интерфейсе) пустую поисковую кампанию с этим названием
   и группу объявлений — CSV сам кампанию с настройками бюджета/гео не создаст.
2. Editor → **Аккаунт → Импорт → Вставить текст** (Account → Import → Paste text),
   либо «Внести несколько изменений» (Make multiple changes).
3. Вставляйте файлы **по одному**, в порядке номеров. Отметьте «Мои данные содержат
   столбцы кампаний и групп объявлений».
4. Файл `06` не импортируется — структурированные описания добавляются только вручную,
   инструкция внутри файла.
5. Если Editor не распознал заголовок столбца — на шаге предпросмотра сопоставьте поля вручную.
6. Проверьте предпросмотр → **Обработать** → затем **Опубликовать** (Post) в аккаунт.

## Что CSV не создаёт — задайте руками в настройках кампании

- **Бюджет и стратегия ставок.** Старт: 40–60 zł/день, «Максимум кликов» с
  ограничением цены клика ~4 zł. Через 15–20 конверсий переключить на «Целевая цена за конверсию».
- **Гео.** Grodzisk Mazowiecki + радиус 15–20 км (захватит Milanówek, Podkowa Leśna,
  Brwinów, Pruszków, Żyrardów). Тип таргетинга — **«Присутствие: люди в целевых
  местоположениях»**, не «интерес» — иначе показы уйдут по всей Польше.
- **Язык:** польский. **Сеть:** только поиск, партнёров поиска и КМС выключить.
- **Расписание показа:** Пн–Сб 8:00–21:00 (салон работает 9:00–20:00).
- **Ассет «Номер телефона»:** +48 881 777 437 — в текст объявлений номер вставлять нельзя,
  это нарушение правил Google.
- **Ассет местоположения:** привязать профиль Google Business (Garbarska 17/2).
- **Отслеживание конверсий:** запись через Booksy кампания не увидит. Настройте событие
  GA4 на клик по кнопке «Umów na Booksy» на своём сайте и импортируйте его как конверсию;
  звонки из объявления считаются автоматически.
- **Суффикс конечного URL** (уровень кампании):
  `utm_source=google&utm_medium=cpc&utm_campaign=depilacja_laserowa`

## Перед запуском проверить

**В профиле Booksy услуги лазерной депиляции должны быть доступны для записи.**
На момент подготовки файлов в профиле видна только позиция
«Darmowa konsultacja + próba laserowa» (бесплатно, 15 мин), а отдельных услуг
(pachy, bikini, nogi) с ценами из объявления не видно. Если их там нет — добавьте,
иначе человек кликает по объявлению с ценой и попадает на страницу без нужной услуги.

Ссылки на booksy.com ведут на сторонний домен, поэтому в тексте дополнительных ссылок
явно указан домен («Rezerwacja na Booksy.com», «Opinie na Booksy.com») — этого требуют
правила Google для ссылок на чужие домены.
